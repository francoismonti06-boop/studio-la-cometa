# Developer Foundation

This directory contains the local development methodology used across projects.

The objective is to produce predictable, reviewable and maintainable code changes using AI-assisted development.

## Structure

rules/
Permanent instructions automatically loaded by Continue.

playbooks/
Step-by-step procedures for recurring development tasks.

prompts/
Reusable prompts for analysis, migration, review and documentation.

assistants/
Specialized assistant profiles.

## Principles

- Smallest possible change.
- One logical change at a time.
- Review every diff.
- Build before commit.
- Never automate Git decisions.
- Preserve existing architecture.
